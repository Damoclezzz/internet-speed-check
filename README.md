# Замер скорости скачивания

Скрипт последовательно скачивает файл по указанному URL 10 раз. Он выводит среднее время полного запроса, общий объём скачанных данных и скорость в **Мбит/с**.

## Запуск

Python 3.10+ и одна зависимость для проверки HTTPS-сертификатов:

```bash
python3 -m pip install -r requirements.txt
python3 speed_check.py "https://upload.wikimedia.org/wikipedia/commons/3/31/Time_to_return_home.jpg"
```

Это [изображение Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Time_to_return_home.jpg) размером 10,8 МБ. За 10 запросов будет скачано около 108 МБ. Вместо примера можно передать прямую ссылку на другой файл. Данные читаются блоками и не сохраняются на диск.

Скорость рассчитывается как `скачанные байты × 8 / суммарное время / 1 000 000`. Мбит/с — мегабиты в секунду, как в интернет-тарифах. Результат зависит также от сервера и возможного кэширования по пути.
